    What to know

      Evidence before generation

      Scope filters, parent validation and linked circulars feed a bounded context. Answers require exact citation quotes. One repair attempt precedes safe abstention.

      Quality in Datadog

      RAGAS scores and optional thumbs feedback join the exported workflow span. Streamlit shows the answer, citations and a Datadog link. “Queued” is a local SDK state.

      Current scope

      LangGraph and an application MCP server are future layers. The mock banking API is a separate fixture. Hybrid search is optional; the local reranker remains off by default.
